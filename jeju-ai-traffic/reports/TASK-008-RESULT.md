## 2. 구현 요약
- 경로 비교 결과 아래 **'길 안내 시작'** 버튼 → 시트에 안내 문구("목적지만 전달하므로 외부 내비의 경로는 이 화면에서 고른 경로와 다를 수 있습니다")와 세 가지 수단.
  - **카카오맵으로 열기:** `https://map.kakao.com/link/to/{이름},{위도},{경도}`(새 창, `noopener`). 이름은 인코딩하고 쉼표는 공백으로 바꿔 구분자와 섞이지 않게 했다.
  - **네이버지도 앱으로 열기:** `nmap://route/car?dlat=&dlng=&dname=&appname={현재 호스트}`. 이동 후 1.5초가 지나도 페이지가 보이면 "앱이 열리지 않았나요? 카카오맵 웹 링크 또는 목적지 복사를 이용하세요." 페이지가 숨겨지면(앱 전환) 판단을 멈춘다.
  - **목적지 복사:** 이름+주소(도로명 우선)를 클립보드에 쓴다. 실패하면 직접 복사할 수 있게 문구 칸을 보여 주고 직접 검색을 안내한다.
- **전달 정보:** 목적지 이름·좌표만. 출발지(현재 위치)와 경유지는 어떤 링크에도 넣지 않는다(테스트로 확인). 제주 범위 밖 목적지면 시트를 보여 주지 않는다.
