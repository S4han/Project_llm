## 3. 구현 요약
- **위치(1.(a))**: 교통시설물 카드의 8번째 유형 "주정차 단속"(건수 표시). 기본은 꺼짐이고, 누르면 지도에 점이 켜진다.
- **점 모양(사용자 점검 뒤 변경)**: 처음 검정 점은 AVI(회색)와 구분되지 않았다(Production 휴대폰 캡처, 370곳 표시 확인). 노란 점 + 검정 테두리로 바꾸고 조금 크게 했으며, 카드의 범례 점도 같게 했다.
- **반경 1km(범위 변경, 처음 5km에서 1km로)**: "주정차 단속"을 켜면 다음 순서로 동작한다.
  1. 현재 위치를 한 번 확인한다(정확도 200m 이내, 10초 제한).
  2. 반경 1km 안 단속 CCTV만 지도에 보인다.
  3. 반경 원(점선)과 내 위치(파란 점)를 그리고, 원이 보이게 확대한다.
  4. 카드 아래에 "내 위치 반경 1km 안 주정차 단속 CCTV N곳 / 위치 다시 확인"을 보인다. 없으면 "없습니다(제주시 자료만 있음)"라고 안내한다.
  - 끄고 다시 켜면 위치를 다시 묻지 않는다.
  - 위치 권한 거부·시간 초과·부정확·제주 밖이면 주정차 단속을 끄고 이유를 안내한다.
  - **위치는 이 기기 메모리에서 거리 계산에만 쓰고 서버로 보내거나 저장하지 않는다.** 서버는 계속 제주시 전체 목록을 받아 CDN에 보관한다.
  - 화면 하단 고지를 "위치정보는 주정차 단속을 켤 때만 한 번 확인하며, 이 기기에서 반경 계산에만 쓰고 서버로 보내거나 저장하지 않습니다."로 바꿨다.
- **팝업(2.(a))**: 예시는 다음과 같다. 수가 비어 있으면 그 항목은 뺀다.
  ```
  주정차 단속 CCTV · 인제 신설오름 부근(고마로, 고마로17길)(특)
  제주시 일도2동 377-23
  회전형 1대 · 검지 2대
  운영 평일 07시30분 ~ 22시
  공휴일 09시 ~ 18시
  (특) 07:30 ~ 23시
  ```
  장소 앞 번호("1. ")는 뗐다. 원천 글자는 HTML로 해석하지 않는다.
- **키(3.)**: `DATA_GO_KR_API_KEY`. 인코딩 키는 그대로, 일반 키는 인코딩해서 붙인다. 키가 없으면 모의 데이터.
- **실패해도 동작**: 주정차 단속만 "불러오지 못했습니다 / 다시 시도"가 나오고, 제주 ITS 시설물은 그대로 보인다.
- **안내**: 카드 설명과 화면 하단 출처에 다음을 적었다.
  - 제주시 자료(공공데이터포털)
  - 서귀포시는 없음
  - 위치와 운영 시간만 있음
