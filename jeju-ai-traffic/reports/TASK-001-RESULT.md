**확인된 사실**
1. **단일 목적지 자동차 길찾기는 제휴 없이 REST 키만으로 호출된다.** C_STAGE_SETUP의 "제휴 전용일 수 있음" 우려는 해소(비상업·무료 쿼터 기준).
2. **BLK-03 (복수 경로):** `alternatives=true`는 두 API 모두 이번 표본에서 대안 경로를 주지 않았다. 대신 `priority` 변경(RECOMMEND vs TIME)과 경유지 지정으로 **서로 다른 도로(평화로 방면/516로/1100로) 경로를 얻을 수 있다.** 후보 경로 3개 = 호출 3회 → 쿼터 3배 소모(일 10,000건 기준 추천 1회당 3건).
3. **BLK-04 (교통 매칭) 우회 가능성:** 응답의 도로 링크마다 `traffic_speed`·`traffic_state`(0~4)가 들어 있다. 공급자가 경로에 붙여 주는 소통 정보이므로 **표준노드링크 매칭 없이 경로별 혼잡 표시가 가능할 수 있다.** 단, 값의 정의(상태 코드 의미)와 갱신 주기는 공식 문서로 재확인 필요, 사건·통제 정보는 없음.
4. 응답 헤더에 잔여 쿼터 정보는 없다 → FR-009 쿼터 관리는 자체 카운터 + 429 처리로 설계해야 한다(AGENTS.md상 자체 카운터만으로 과금 차단을 보장하지 않음 — 카카오는 429 차단형이라 과금 위험은 없음).
5. 소통 정보가 `duration`에 반영되는지(실시간 vs 통계)는 미확인.

### C-2. 제주 교통정보 (실시간 링크 소통 15093660, C-ITS 15079829)
- 두 데이터는 data.go.kr 게이트웨이가 아닌 **LINK형**이다. 참고문서(data.go.kr 다운로드) 기준:
  - 실시간 교통정보: `http://api.jejuits.go.kr/api/getFrafficInfo?code=키` (link_id, 교통량, 평균속도, 점유율, 통행시간)
  - C-ITS: `http://{ip}/api/infoRoadEventList`, `infoRoadCloseList`, `infoRoadWorkList` 등 (`code=키`)
  - **키는 공공데이터포털 서비스키가 아니라 제주 ITS가 발급하는 `code`** 로 보인다(문서상 "제공한 키"). 현재 `JEJU_ITS_API_KEY` 없음.
- **차단 1:** `api.jejuits.go.kr`가 작업 환경 허용 도메인에 없어 프록시가 403 차단(1건 시도, 서버 미도달). 또 API가 `http://`(비암호화)라 키가 평문으로 전송된다.
- **차단 2:** `www.jejuits.go.kr`가 이 클라우드 환경(해외 IP)의 요청을 **웹 방화벽으로 차단**한다. API 서버도 해외 IP를 막는다면 Cloudflare Workers(해외 엣지) 경유 호출도 막힐 수 있다 → **운영 구조의 전제에 영향**. 우회는 시도하지 않았다.
- 따라서 FR-005 공공 교통정보·사건 연동은 **미검증**.
