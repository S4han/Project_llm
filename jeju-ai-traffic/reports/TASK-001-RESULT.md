- **BLK-06 — 제주 ITS 해외 IP 차단 추정.** 키 문제 아님(키 없이 홈페이지도 차단). 운영 서버(Cloudflare Workers 등)가 해외 IP로 나가면 같은 차단을 받을 수 있어 **호스팅 구성에도 영향**. 확인 방법: 사용자가 국내 회선(아이패드 셀룰러/가정 Wi-Fi)에서 jejuits.go.kr 접속 가능 여부 확인, 오픈API 문서의 호출 URL 확인.

#### 판정 — BLK-04
- **좌표 근접 매칭은 동작한다.** 매칭된 항목 대부분이 도로 축에서 200m 이내(0~164m). 표준노드링크 형상 데이터 없이도 MVP 수준의 "경로 주변 사고·통제·기상" 표시는 가능하다.
- **도로 구간별 실시간 속도는 제주 ITS 오픈API에 없다.** 구간 혼잡도는 카카오 응답의 `traffic_state`(블록 평균, §10.2)를 1차로 쓰고, VMS의 방향별 소요시간·소통색을 보조 근거로 쓸 수 있다(VMS `시간` 값의 단위는 미확인 — 분으로 추정).
- **돌발 정보는 평화로에 몰려 있다.** C-ITS 실증 구간 특성으로 보이며, 1100도로·516도로는 돌발 정보가 비어 있을 수 있다 → PRD AC-005-03의 '정보 미확보' 표시가 필요하다.
- 데이터 품질 처리 필요: 무효 좌표(`90,180`), 결측값(`-1`), 같은 위치 중복 이벤트.
- 정리: 저장소 최상위 확인용 파일 3개는 시험 후 삭제. Vercel 프로젝트 `jeju-its-probe`와 환경 변수는 남아 있음(삭제는 사용자 수행).
