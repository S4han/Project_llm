## 3. 구현 요약
- **들어가는 곳**: 대시보드 "그 밖의 정보" → **관광 검색**(검색하기 ›) → `/search`.
- **위쪽**
  - 검색창과 카테고리 칩(전체·관광지·숙박·음식점·카페)
  - **내 주변**: 위치가 되면 반경 3km를 가까운 순으로 보입니다. 위치 권한이 없거나 제주 밖이면 이유를 알리고 **지역 고르기**(제주시내·애월·한림·협재·함덕·조천·성산·표선·서귀포시내·중문·대정·모슬포 9곳)를 보입니다(참고 PRD 수동 지역 입력).
  - 검색어와 카테고리는 주소(`?q=&cat=`)에 남고, 위치는 남기지 않습니다.
- **지도와 목록**
  - 카테고리별 색 동그라미로 표시합니다(관 남색·숙 자주·식 주황·카 갈색). 검색하면 결과가 모두 보이게 지도를 맞춥니다.
  - 목록은 30곳씩 보이고 "더 보기"로 늘립니다. 한 줄에 사진(없으면 카테고리 표시), 이름, 거리, 카테고리, 주소, **출처**(예: 비짓제주·한국관광공사)가 나옵니다.
  - 넓은 화면에서는 지도가 왼쪽, 목록이 오른쪽입니다.
- **상세 카드**(목록이나 지도 점을 누르면)
  - 사진(출처 표시), 전화, 거리(또는 출처 수), 소개, 주소, 특징을 보입니다. 없는 값은 **"정보 없음"**으로 둡니다(참고 PRD FR-006).
  - 출처와 기준 시각(목록 HH:MM, 카카오 HH:MM)을 함께 적습니다.
  - 아래에 "현재 위치에서 경로 안내"(이 서비스)와 링크(비짓제주 상세, 카카오맵, **카카오맵 길찾기**, 모두 새 창)가 있습니다.
- **부분 결과**: 묶음 하나나 카카오가 실패하면 "일부 정보 누락: ○○을(를) 불러오지 못했습니다. 다른 출처 결과만 보여 줍니다"라고 알립니다. 목록 전체가 실패하면 "다시 시도" 버튼을 보입니다.
- **카카오 실시간**
  - 카테고리가 전체·음식점·카페일 때만 부릅니다. 검색어가 있으면 키워드 검색 1건, 내 주변이면 음식점·카페 카테고리 검색 1~2건입니다.
  - 결과는 서버와 CDN 어디에도 보관하지 않습니다(no-store).
  - 목록 결과와 합친 뒤 다시 줄 세웁니다. 카카오가 찾아 준 곳은 이름이 검색어와 달라도 맨 뒤에 남깁니다.

## 6. 비용·보안
- **비용**: 0원.
  - 비짓제주: 검색 목록을 새로 만들 때 약 42건이 듭니다(숙소 10건과 별도). 서버 하루·CDN 7일 보관이라 평소에는 하루 수십 건입니다. 내부 한도는 200건/일 그대로입니다.
  - 관광공사: 3건입니다(내부 한도 800).
  - 카카오: 검색 수만큼입니다(기존 한도 3,000/일 안).
- **키**: 서버 전용입니다(`VISITJEJU_API_KEY`, `DATA_GO_KR_API_KEY`, `KAKAO_REST_API_KEY`). 새 키는 없습니다. 카카오 실시간은 장소 검색과 같이 `PLACES_PROVIDER=kakao`일 때만 켜집니다.
- **위치**: "내 주변"을 누를 때만 확인합니다. 카카오 검색에는 약 100m 단위로 줄인 좌표만 보내고, 주소·저장·로그에는 남기지 않습니다. 이 내용은 화면 아래에 안내합니다.
- **화면 안전**: 원천 글자는 textContent로만 넣습니다. 사진은 비짓제주와 관광공사 사진 서버의 https 주소만 씁니다. 바깥 링크는 https, 새 창, opener 차단입니다.

## 7. 남은 이슈
1. **약관(참고 PRD G-02)**: 비짓제주·관광공사·카카오 자료를 함께 보이고 합치는 일이 각 약관에 맞는지 공식 문서로 확인하지 못했습니다. 카카오 결과는 저장하지 않고 모든 결과에 출처를 붙였습니다. 상업적으로 쓰기 전에 확인이 필요합니다.
2. **후속 TASK로 미룬 것(4.(a))**: 참고 PRD의 운영자 대시보드, 관리자 인증, 경고 이메일, 이력 90일, 서명 키, 멱등성, 공유 사용량 저장소(OPS-AC596~605 등). 지금 사용량 관문은 서버 메모리 기준이라 인스턴스마다 따로 셉니다.
3. **목록 크기**: 목록은 약 4,500곳(압축 전 1MB대)이고 페이지를 열 때 한 번 받습니다. CDN이 압축해 보내지만, 느린 휴대폰 망에서는 첫 검색까지 몇 초 걸릴 수 있습니다.
4. **비짓제주 한도**: 숙소(10건)와 검색 목록(42건)이 같은 내부 한도 200을 씁니다. 함수 인스턴스가 하루에 여러 번 새로 뜨면 한도에 걸려 일부 묶음이 빠질 수 있습니다. 이때는 부분 결과 안내가 나오고 10분 뒤 다시 받습니다.
5. **카페 구분**: 비짓제주는 이름·태그(카페·커피·디저트·베이커리)로, 관광공사는 분류 코드로 나눕니다. "와인카페"처럼 애매한 곳은 카페로 들어갈 수 있습니다.
6. **관광공사 상세 링크 없음**: 공개 상세 주소에 쓰는 번호가 목록에 없어, 출처 이름만 보이고 링크는 달지 않았습니다.
7. **실데이터 확인**: 실기기와 실데이터 확인은 Preview에서 필요합니다.
