# CLAUDE.md — Claude Code 작업 지침

이 프로젝트의 실행 주체는 **Claude**다(사용자 지정, 2026-10-18). 공통 작업 규칙은 `AGENTS.md`에 있으며 그대로 따른다.

@AGENTS.md

## Claude 적용 방법
- `AGENTS.md`·`START_HERE.md`의 "Codex"는 **이 프로젝트를 실행하는 에이전트(현재 Claude)** 로 읽는다. 대화 프로토콜(`시작`/`다음`/`상태`/`계획 승인`/`완료 승인`/`보류`)과 승인 규칙은 동일하다.
- 매 응답 전에 이 폴더의 `TASK_STATUS.md`, `DECISIONS.md`를 확인한다. 진행 중인 TASK에 준비 문서가 있으면 함께 읽는다(예: `docs/C_STAGE_SETUP.md`).
- 이 저장소에는 다른 프로젝트도 있다. 사용자가 `jeju-ai-traffic 상태`처럼 폴더 이름을 붙이면 이 폴더의 프로토콜을 적용한다.

## 저장소
- 기준 저장소: GitHub `s4han/project_llm`의 `jeju-ai-traffic/`. 구글 드라이브 `jeju-ai-traffic` 폴더는 보관본이므로 읽거나 갱신하지 않는다.
- 상태·결정 문서의 변경은 사용자 승인 근거가 있을 때만 커밋한다. 커밋 메시지에 관련 TASK와 승인 문구를 적는다.

## 비밀정보
- API 키는 클라우드 환경 설정(Network secrets 또는 환경 변수)으로만 받는다. 사용자에게 키를 대화창에 붙여넣으라고 요청하지 않는다.
- 키 값을 출력·로그·파일·커밋에 남기지 않는다. 존재 여부만 확인한다.

## 동시 작업 금지
Codex 등 다른 에이전트와 같은 저장소에서 동시에 쓰기 작업을 하지 않는다. 실행 주체를 바꾸려면 사용자 결정을 `DECISIONS.md`에 먼저 기록한다.
