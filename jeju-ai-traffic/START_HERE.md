# START_HERE.md — Codex 앱에서 시작하기 (v0.3)

## 사용자 최초 설정
1. ZIP을 Windows PC에 내려받고 압축을 푼다. 압축 내부의 프로젝트 폴더를 Codex 앱에서 **로컬 프로젝트/작업 폴더**로 연다. 앱 버전에 따라 `Open project`, `Add project` 등의 표시가 다를 수 있다.
2. 프로젝트 최상위에 `PRD.md`, `AGENTS.md`, `IMPLEMENTATION_PLAN.md`, `TASK_STATUS.md`, `DECISIONS.md`, `tasks/`가 있는지 확인한다.
3. Codex 앱에서 해당 프로젝트 대화를 시작하고 **`시작`** 한 단어를 보낸다. 앱이 자동으로 새 대화를 생성하거나 작업을 실행한다고 가정하지 않는다.
4. Codex가 `TASK-001`의 계획만 제시하면 내용을 읽는다. 승인할 때만 **`계획 승인: TASK-001`**이라고 보낸다.
5. Codex가 결과를 보고하면 `reports/TASK-001-RESULT.md`와 테스트/미검증 사항을 확인한다. 적합할 때만 **`완료 승인: TASK-001`**이라고 보낸다.
6. 다음 TASK는 **`다음`**이라고 보낸다. 이 메시지는 **계획 요청**일 뿐 실행 승인이 아니다.

## 짧은 명령표
| 입력 | Codex 동작 | 변경 가능 여부 |
|---|---|---|
| `시작` 또는 `다음` | 현재 대기 TASK 계획 작성 및 승인 요청 | 없음 |
| `상태` | 현재 TASK·대기 승인 확인 | 없음 |
| `계획 승인: TASK-001` | 해당 TASK 실행 (별도 고위험 승인 필요) | 해당 TASK만 |
| `완료 승인: TASK-001` | 결과 승인 기록·다음 TASK 대기로 변경 | 상태 문서만 |
| `보류` 또는 `반려` | 중지하고 재검토 | 없음 |

## 유의사항
- `AGENTS.md`는 Codex가 참고하는 프로젝트 지침이지만 **앱에서 폴더를 열기만 해도 자동으로 작업이 시작되는 것은 아니다.** 최초 `시작` 메시지가 필요하다.
- 자동 상태 변경은 Codex가 프로젝트 파일을 읽고 쓸 수 있어야 동작한다. 앱에서 파일 접근/실행 승인을 별도로 요구할 수 있다.
- `계획 승인`은 실제 외부 API 과금, 결제 수단 등록, 계정 생성, 비밀키 사용, 실서비스 배포에 대한 승인이 아니다.
- PRD는 원본 그대로 유지한다. 기술 스택은 제안이며 P0 검증 후 결정한다.
- 대화가 길어지거나 새 대화로 옮겨도 `TASK_STATUS.md`를 읽고 현재 작업을 재개한다. 문서 상태와 대화 내용이 충돌하면 중지하고 확인한다.
