| 상태 | 의미 | 다음 상태로 바뀌는 조건 |
|---|---|---|
| 미착수 | 아직 순서가 오지 않음 | 이전 TASK `완료 승인` 시 `대기` |
| 대기 | 계획 요청을 기다림 | `시작`/`다음` → 계획 제시 후 `계획 검토` |
| 계획 검토 | 계획 제시됨, 사용자 승인 대기 | `계획 승인: TASK-XXX` → `진행 중` |
| 진행 중 | 승인된 범위 내에서 실행 중 | 실행 종료 + 결과 보고서 작성 → `결과 검토` |

| 완료 | 사용자가 결과 승인 | — |
| 보류 | 사용자가 `보류`/`반려` 지시 | 사용자가 수정 계획 승인 |
