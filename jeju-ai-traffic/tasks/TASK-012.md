# TASK-012 — ITS 실시간 교통 현황 대시보드

- 상태: **진행 중** (범위 확장: 실시간 교통정보 API 구간 속도, 2026-10-20) (사용자 "계획 승인: TASK-012 1. (a) 2. (b) 3. (a) 4. 승인", 2026-10-20)
- 관련 PRD: 없음(MVP 이후 추가 기능, 사용자 요청 2026-10-20). NFR-002·003·004·005·007·009 준수
- 선행 작업: TASK-011

## 목적 및 범위
제주 ITS 돌발·통제·공사 정보를 제주 전체 지도와 종류별 건수·목록으로 보여 주는 별도 화면(`/traffic`).

## 명시적 제외
VMS·교통기상·구간 속도(오픈API에 없음), 추가 제주 ITS 확인 호출, 카카오 호출, PRD 수정.

## 실행 항목
- `GET /api/traffic/incidents`: 기존 제주 ITS 어댑터·60초 캐시·일일 한도(2,000) 공유, IP별 빈도 제한
- `/traffic` 화면: 지도(전체 사건), 종류별 건수, 종류 필터, 묶음 목록(지도에서 보기·다음 지점·전체 보기), 조회 시각·오래된 정보·실패/한도 안내
- 화면이 켜져 있을 때만 1분 자동 갱신, 숨김 시 멈춤
- 경로 화면과 오가는 링크, 하단 고지·운전 중 조작 금지 문구
- `vercel.json` 주소 연결(`/traffic` → 화면)

## 수용 기준 및 테스트
단위(처리기·화면), e2e(모의 사건), 캡처. 실패·한도 시 안내, 정보 없음을 '이상 없음'으로 표현하지 않음.

## 사용자 확인 지점
결과 검토 후 완료 승인. main 반영은 별도 지시.
