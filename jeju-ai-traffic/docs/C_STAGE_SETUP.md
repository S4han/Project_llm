## ⚠️ 새로 확인된 사항 (C단계 전제 변경 가능)
검색 결과(공식 문서 발췌)에 따르면 카카오모빌리티의 **단일 목적지 "자동차 길찾기" API는 문서 경로가 `/affiliate/`(제휴 전용)** 이고 "사전 제휴 계약 필요"로 안내되어 있다. 데브톡에는 "자동차 길찾기 API 사용 권한 요청" 글이 다수 있다. 즉 **키를 발급받는 것만으로는 바로 호출되지 않을 수 있다.**
- 대안 후보: **다중 경유지 길찾기** API — 일반 개발자 가이드 경로(`/guide/`)에 있고 `alternatives`(대안 경로) 파라미터가 있다. REST 키만으로 쓸 수 있는지는 미확인.
- 따라서 C단계 첫 호출에서 ① 자동차 길찾기 ② 다중 경유지 길찾기 순으로 **권한 여부부터 확인**한다(각 1~2건).
- 둘 다 권한이 없으면 데브톡으로 권한 요청(아래 1-⑤)을 하거나, 공급자 결정을 다시 받는다(TMAP 대안).

## 아이패드 공통 요령
- 모든 작업은 **Safari**에서 한다. 화면이 깨지거나 버튼이 안 보이면 주소창 왼쪽 **`가가`(또는 `aA`) 버튼 → "데스크탑 웹사이트 요청"**을 누른다.
- 키 복사: 키 글자를 **길게 눌러 선택 → "복사"**. 복사 버튼이 있으면 그 버튼을 쓴다.
- 복사한 키는 **바로 3단계 화면에 붙여넣는다.** 메모 앱·카톡·사진(스크린샷)에 임시로 저장하지 않는다.
- 탭을 여러 개 열어 두면 편하다: 카카오 디벨로퍼스 / 공공데이터포털 / claude.ai/code.

## 1. 카카오 REST API 키 발급
1. Safari에서 https://developers.kakao.com 접속 → 오른쪽 위 **로그인** → 본인 카카오 계정으로 로그인. (아이패드에 카카오톡이 있으면 "카카오톡으로 로그인"이 편하다.)
2. 처음이면 **개발자 등록** 화면이 나온다. 약관에 동의하고 진행한다(휴대폰 인증을 요구할 수 있음).
3. 상단 메뉴 **앱**(또는 "내 애플리케이션") → **앱 생성**(＋ 버튼).
   - 앱 이름: `jeju-ai-traffic-test` (아무 이름이나 가능)
   - 회사명/사업자명: 개인이면 본인 이름
   - 카테고리: 교통 또는 지도/내비게이션(있는 것 중 가까운 것)
   - 운영정책 동의에 체크하고 **저장**.
4. 만든 앱 선택 → **앱 키**(신규 화면은 "플랫폼 키") 메뉴 → **REST API 키** 값을 확인한다.
   - 지금은 **복사하지 말고 화면만 확인**해 둔다. 3단계에서 이 탭으로 돌아와 복사 → 바로 붙여넣는다.
   - "호출 허용 IP 주소" 칸은 **비워 둔다.** 클라우드 세션의 IP는 고정되지 않아 IP를 제한하면 호출이 막힌다.
5. (권한 확인 후 필요할 때만) 권한 요청: https://devtalk.kakao.com → **카카오내비** 카테고리 → 새 글. 제목 예: "자동차 길찾기(Directions) API 사용 권한 요청". 본문에 **앱 ID(숫자)**, 용도("개인 비상업 웹서비스 기술 검증, 무료 쿼터 내 소량 호출")를 적는다. **REST API 키는 절대 쓰지 말 것.** 앱 ID는 앱 목록/요약 정보에 표시되는 숫자이며 비밀이 아니다.
6. 하지 말 것
   - 앱 화면에서 **비즈월렛 연결**, **유료 API 사용 설정**, 결제수단 등록 안내가 뜨면 **중단**한다.
   - 지금은 **카카오맵 API 활성화도 하지 않는다.** 카카오맵 무료 쿼터는 계정에서 처음 활성화한 앱 하나에만 주어지므로, 나중에 실제로 쓸 앱에서 켠다.

## 2. 공공데이터포털 서비스 키 발급
1. Safari에서 https://www.data.go.kr 접속 → **회원가입**(개인) 후 로그인. 화면이 작게 나오면 "데스크탑 웹사이트 요청"을 켠다.
2. 상단 검색창에 `제주특별자치도_실시간 교통정보` 검색 → 결과 중 **오픈API** 탭의 항목 선택(데이터 번호 15093660).
3. 상세 화면의 **활용신청** 클릭 → 입력:
   - 활용목적: **웹 사이트 개발**(또는 "기타")
   - 상세 기능정보 / 활용 내용: "개인 비상업 교통 경로 추천 웹서비스의 기술 검증(소량 호출)"
   - 라이선스 표시에 동의 → **활용신청** 완료.
4. 같은 방법으로 `제주특별자치도_제주 C-ITS 교통정보`(15079829)도 활용신청.
   - 상세 화면이 **jejuits.go.kr로 이동해 별도 신청**하라고 안내하면, 그 사이트에서 신청한다. 그 경우 키가 따로 나오므로 3단계에서 변수를 하나 더 만든다(`JEJU_ITS_API_KEY`).
5. 승인 확인: **마이페이지 → 데이터활용 → Open API → 활용신청 현황**(메뉴 이름은 조금 다를 수 있음). 상태가 **승인**이면 완료다. 보통 자동승인이지만 10분~1일 걸릴 수 있다.
6. 같은 화면의 **일반 인증키**에 **Encoding**과 **Decoding** 두 개가 있다. → **Decoding 키**를 쓴다(URL 인코딩은 Claude가 호출할 때 처리).
   - 서비스 키는 계정당 하나라 두 API 모두 같은 키를 쓴다. 다만 키가 실제로 동작하기까지 1~2시간 걸릴 수 있다.

## 3. 키를 Claude 작업 환경에 등록
키는 **대화창이 아니라 클라우드 환경 설정**에 넣는다. 설정 화면은 claude.ai/code에서 연다(아이패드 Safari 권장).
1. Safari 새 탭에서 https://claude.ai/code 접속 → 메시지 입력창 **바로 위 줄에 있는 구름 아이콘(현재 환경 이름)** 을 탭한다.
2. 환경 목록이 열린다. PC에서는 마우스를 올리면 오른쪽에 **설정(톱니) 아이콘**이 나타나는데, 아이패드는 마우스가 없으므로:
   - 지금 쓰는 환경 줄의 **오른쪽 끝을 탭**해 톱니 아이콘이 보이는지 확인한다.
   - 안 보이면 그 줄을 **길게 눌러** 본다.
   - 그래도 안 보이면 주소창 `가가` → **데스크탑 웹사이트 요청** 후 다시 시도한다. (아이패드에 트랙패드/마우스를 연결했다면 포인터를 올리면 된다.)
   - 위 방법이 모두 안 되면 화면에 보이는 버튼 이름을 Claude에게 알려 준다.
3. 편집 화면에서 등록 방법은 두 가지다. 화면에 있는 것을 쓴다.

### 방법 A (권장, 화면에 있을 때): Network secrets / API credentials
키를 Claude가 직접 보지 않고, 요청이 나갈 때 프록시가 키를 붙여 준다(Pro·Max 요금제에서 제공).
- 카카오:
  - 호스트: `apis-navi.kakaomobility.com` (권한 확인 후 `dapi.kakao.com`도 같은 키로 하나 더)
  - 방식: HTTP 헤더 `Authorization`, 값 `KakaoAK ` + REST API 키 (**`KakaoAK` 뒤에 공백 한 칸**)
- 공공데이터포털: 키를 **URL 쿼리(`serviceKey=`)** 로 보내는 방식이다. 이 화면이 쿼리 파라미터 주입을 지원하지 않으면 방법 B를 쓴다.
- 입력 칸 이름이 위와 다르면, 화면에 보이는 **칸 이름만** 알려 주면 된다(키 값은 알려 주지 말 것).

### 방법 B: Environment variables
`.env` 형식으로 한 줄에 하나씩 입력한다.
```
KAKAO_REST_API_KEY=여기에_REST_API_키
DATA_GO_KR_SERVICE_KEY=여기에_Decoding_키
```
- 입력 순서(아이패드): 위 두 줄의 **변수 이름과 `=`까지만 먼저 입력** → 카카오 탭으로 가서 키 복사 → 돌아와 `=` 뒤에 붙여넣기 → 공공데이터 탭에서도 같은 방식.
- `=` 앞뒤에 공백을 넣지 않는다. 따옴표도 쓰지 않는다. 아이패드 자동 수정(자동 대문자·스마트 따옴표)이 끼어들지 않았는지 확인한다.
- 주의: 환경 변수는 **비밀 보호가 되지 않는다.** 이 환경을 쓰는 사람과 세션 안의 Claude가 값을 읽을 수 있다. 다른 사람과 공유하는 환경이면 방법 A를 쓰거나, 테스트 후 키를 재발급(폐기)한다.

## 4. 네트워크 허용 도메인 추가 (같은 편집 화면)
1. **Network access** 항목 → **Limited**(구버전 앱은 **Custom**) 선택.
2. **Allow package managers**(기본 목록 포함) 체크는 **그대로 둔다.**
3. **Allowed domains** 칸에 한 줄에 하나씩 입력(이 블록을 길게 눌러 복사 → 붙여넣기 해도 된다):
```
apis-navi.kakaomobility.com
dapi.kakao.com
developers.kakaomobility.com
developers.kakao.com
apis.data.go.kr
www.data.go.kr
jejuits.go.kr
www.jejuits.go.kr
```
4. **저장**.
